# Short-Term-PFKFB3_mouse_study
This directory is used to reproduce the figures used from bulk RNA-seq and GeoMx spatial dataset in the paper <b> "Endothelial PFKFB3 deletion attenuates lipid accumulation and pro-inflammatory macrophage phenotype in early atherosclerosis" </b>

<ol>
  <li>
  <b>bulk_RNA_seq_public_dataset_PFKFB3 parsing.R:</b> Processing for the bulk RNA-seq of endothelial cells treated with several inflammatory mediators ( i)GSE118815 ii)GSE213111 iii)GSE184512 iv) GSE131590 ); thereby parsing fold change of PFKFB3 gene.
  </li>
  <li>
  <b>bulk_rnaseq_PFKFB3_KO_mice.R:</b> Processing for the bulk RNA-seq of endothelial cells isolated form PFKFB3 Knock out mice and Control mice and showing comparison of CAM and EndoMT genes
  </li>
  <li>
    <b>geomx_spatial_transcriptomics.R:</b> Processing of GeoMX spatial trascriptomics dataset and cellular decomposition 
  </li>
  <li>
    <b>munich_glyco_infla.ipynb:</b> Parsing glycolytic feature in the the endothelial cells in Munich vascular biobank dataset (https://doi.org/10.5281/zenodo.17520898)
  </li>
  <li>
    <b>plaque_matrix.sh:</b> psudo-bulk profile of top expressing conserved genes derived from the plaque atlas dataset (https://datasets.cellxgene.cziscience.com/ad9f52c0-054b-4dc5-944c-46c376a544cf.h5ad) 
  </li>
</ol>
